# Predicción de riesgo académico en matemáticas

Proyecto de ciencia de datos orientado a identificar posibles casos de bajo rendimiento en matemáticas y apoyar el acompañamiento docente.

## Contenido
- Análisis exploratorio y preparación de datos.
- Entrenamiento y comparación de modelos de clasificación.
- Evaluación del desempeño y auditoría de equidad por subgrupos.
- Predicciones para nuevos casos y automatización por lotes.
- Exportación de resultados para su uso en Power BI.

## Ejecución
Abrir el cuaderno `.ipynb` en Google Colab y ejecutar las celdas en orden. El código descarga los datos desde Kaggle y genera los archivos de resultados.

## Consideraciones
Se utilizan datos sintéticos y un corte provisional de 60 puntos para definir bajo rendimiento. Las predicciones requieren revisión docente y no sustituyen el criterio profesional.
